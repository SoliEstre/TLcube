# TLcube 스캐너 (tlscan.estre.so)

> TrilLuminance (cube) 코드를 카메라나 사진에서 읽는 웹 스캐너. 설치 없이 브라우저에서
> 동작하고, 프레임은 **기기 안에서만** 처리한다(서버로 이미지를 보내지 않는다).

## 이 페이지가 하는 일

카메라를 전체화면 배경으로 띄우고 가운데 가이드 안에 코드를 맞추면 읽는다.
사진에서 읽는 경로도 있다. 읽은 뒤:

- URL → 새 창으로 연다
- Wi-Fi → 네트워크 설정 스키마로 넘긴다
- 텍스트·명함 → 화면에 내용을 보여준다

## 현재 상태 (2026-08-13 실측, 실기기 사진 9장)

**동작한다.** 세 타입 모두 실기기 사진에서 읽힌다 — 지금은 속도 개선 단계다.
짧은 변 1440px 기준:

- Type Y (단일 큐브) — 복호 3 / 3, 약 0.85초
- Type O (육각 필드) — 복호 3 / 3, 약 2.2초
- Type A (삼각 실루엣) — 복호 3 / 3, 약 1.0초
- 중앙 QR 변형 — 복호 8 / 9

복호 시간이 실시간 체감을 지배한다(0.3초 루프에서 그보다 긴 복호는 프레임을 버린다).
라이브는 더 작은 프레임을 보므로 실제로는 더 빠르다 — 960px 판에서 Y 0.6초 · A 0.66초 ·
O 1.4초. 지난 갱신보다 시간이 늘었는데, 파인더 재설계와 포맷 재판독이 인식률을 시간으로
샀기 때문이다(Type A 가 2/3 → 3/3).

## 잘 읽히게 찍는 법

- **셀당 9픽셀**이 복호 하한이다. 코드가 화면에서 작으면 못 읽는다 — 가까이 가져간다.
- **초광각 렌즈를 피한다.** 같은 거리에서 코드가 훨씬 작게 담긴다
  (실측: 초광각 7.6px 실패 / 광각 9.1px 성공). 렌즈가 여러 개인 기기에서는
  화면 하단의 렌즈 선택으로 바꿀 수 있다.
- 강한 반사·글레어가 코드를 가로지르면 실패할 수 있다.
