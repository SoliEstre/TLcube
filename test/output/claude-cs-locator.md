  1. **v2r2 블록 B 의 QR 동심 사각형은 면 T 에만 있다** (L·R 면은 별개 비대칭 패턴).

  2. **v2r2 중앙(블록 A 셀 (0..3)², 3면 합집합)은 Y-심 중심 동심 육각 링**이다:
     r<1 어두움 · 1..2 밝음 · 2..3 대체로 어두움 · 3..4 전부 밝음 → 중심 통과 직선 런렝스
     서명 = [D1 B1 **D2** B1 D1] (1:1:2:1:1 회문). 면 T 블록 B 동심 중심(격자 (n−3.5,n−3.5))도
     **정확히 같은 회문 코어**를 갖는다 (B1 D1 B1 D2 B1 D1 + 코너 밖 배경).
     → 브리프의 «v2r2 는 대각 2개» = 중앙 + T면 먼 코너, 둘 다 같은 검출기로 잡힌다.
  3. **v0 중앙(NW 블록 3면 합집합)은 반지름 2 어두운 육각 + 2..3 밝은 링 불스아이** —
     서명 [B1 **D4** B1] (1:4:1). 세 면 NW 패턴이 동일함을 확인. SE 코너 패치는
     T·L = 밝은 L자 + 어두운 2×2, R = 어두운 3×3 + 중앙 밝은 점 1개 (R 패치가 회전 3중성을 깬다).

## 탐색기 설계 (확정본)

`src/decoder/cellsurface-block-detect.js` — luma 만 입력받는 단독 로케이터. 마스크·실루엣 무의존.

1. **축소**: `downsampleLumaForSeed` (긴 변 480).
2. **1-D 이진화**: 스캔라인/레이 방향 sliding min-max(deque O(n), 반지름 ≈ 1.3셀) 계층 규칙 —
   창 최대 < 0.4·Otsu → 전부 어두움 · 창 최소 > Otsu → 전부 밝음 · 대비 실하면 국소 중간값 ·
   평탄하면 전역 Otsu. 톤은 절대값이 아니라 **라인 국소 순위/대비**로만 쓴다.
3. **회문 코어 스캔**: 4방향(행·열·대각·반대각) 런렝스에서
   K5 = (B1, D2, B1) → v2r2 앵커(중앙·T코너 공용 코어), K3 = (B1, D4, B1) → v0 불스아이.
4. **클러스터·검증**: u-유사 병합 → 후보별 8-레이 교차거리 검증(동심 닮은꼴 링의
   방향 무관 비율 1:2:3:4 / 2:3) + t1 중앙값 일관성 + 중심 재추정 2회.
   v2r2-중앙(닫힌 링) / v2r2-코너(배경으로 열린 링) / v0-중앙을 분류, 실패 시 교차 검증.
5. **포즈 조립**:
   - v2r2: 중앙+코너 쌍 → n 스냅(거리/셀 ≈ n−3.5 로 21|25 판별) → similarity
     (코너 = 면 T 대각 (0,−1)·(n−3.5) 이므로 **회전이 즉시 확정**).
   - v0: 불스아이(위치·스케일) → 30셀 전체 템플릿 회전×스케일 스윕(3°×4스케일 → 0.75°)
     — R면 SE 패치(어두운 3×3+밝은 점)가 3중 회전성을 깬다.
6. **정합 3라운드**: 블록 패치 Pearson 정합(±1.25셀 → ±0.5셀) ×4앵커 estimateHomography4
   → 6\~12 서브앵커(±0.5셀, 5-탭) **최소제곱 DLT** 재적합.
7. **주입**: `cellSurfaceOnly` shape (estimatedN 포함) 로 기존 `hypothesesFromShapes` 에 —
   셀 표면 평가만 받고 **수용은 기존 CS 게이트(0.78/0.035/0.012) 그대로**. lab
   (`enableCellSurfaceY`) 전용, `csBlockLocator:false` 로 끌 수 있음. 로케이터가 수용
   기하를 만들면 소프트 탐침은 건너뜀(비용 절약), 못 만들면 종전 조건 그대로 탐침.

**결정성**: RNG 없음 · 전 순회 고정 순서 · 정렬 전부 명시적 동점 해소 · 회귀 테스트로
같은 프레임 2회 → deepEqual 고정.

## 실사 120° 슬롯

실기기 실측(2026-08-15 밤): 성공 20프레임의 슬롯 분포 0°=10 · 240°=10 · **120°=0** —
세 방향 가설 중 120° 슬롯이 실사에서만 통째로 죽어 있다 (합성 grid-match 18/18 정상).

1. **합성 슬롯별 벤치** (물리각 90/105/120/135/150° 포함, 위 98 매트릭스에 내장):
   수정 전에도 합성에서는 120° 슬롯 자체가 살아 있었다 (무왜곡 rot90\~135 슬롯 120,
   rot150 은 120/240 경계) — 실사 전용 병리라는 실측 판독과 일치. 따라서 **합성으로는
   죽음 자체를 재현할 수 없고**, 여기서 잴 수 있는 것은 «로케이터 경로가 그 결정
   지점을 우회하는가»다.
2. **로케이터의 구조적 면역**: 실루엣 경로의 슬롯은 hull 꼭짓점 배열 시작점(정점 0 선정)
   → `cubeGeometrySeeds` 의 phase shift 매핑을 거쳐 정해진다 — 120° 슬롯 사멸의 추정
   결정 지점이 바로 이 단계다(꼭짓점 0 선정 규약이 특정 회전대 + 원근에서 요동).
   블록 로케이터는 **hull 꼭짓점을 아예 소비하지 않는다**: v2r2 는 QR 모티프 코너가
   면 T 임을 직접 식별하고, v0 는 R면 SE 점 패턴이 3중 회전성을 깬다. 물리 회전은
   H 에 흡수되고 가설은 **항상 orientation 0** 으로 나온다 (수정 후 벤치에서 물리각
   90\~150° 케이스 대부분이 슬롯 0 으로 복호되는 것이 그 표지 — 슬롯은 죽을 자리가 없다).
3. **결정 지점 기록** (수정은 범위 밖, 규약 실재는 코드로 확인): `simplifyHullToHex`
   (cube-detect.js:737\~) 는 꼭짓점 0 을 **y-최소(상단, 동률이면 x-최소)** 로 회전시킨다
   — 운영자 추정의 그 규약이 실재한다. 이것이 `cubeGeometrySeeds` 의
   `shift = (seamParity − 1 + 2·orientation) mod 6` 매핑과 만나는 곳이 유력 결정 지점:
   물리 회전이 꼭짓점 두 개의 y 를 근접시키는 회전대(±원근 요동)에서 꼭짓점 0 선정이
   한 칸 튀면 홀수 shift 가 필요한데 기본 경로는 짝수 shift(0/2/4)만 커버한다
   (`adjacentPhase` 는 locator 후보에만 열린다). v0 합성 150° 취약(미규명)도 같은 뿌리일
   개연성. 단 여기까지는 **코드 판독 + 실측 분포와의 정합**이고, 실사 죽음의 직접 재현은
   못 했다 — 재배포 후 실측으로 확정해야 한다 (로케이터 가설이 실사에서 슬롯 무관
   복호를 만들면 이 진단이 강하게 지지된다).

## 소프트 탐침과의 관계 — 판정: 대체가 아니라 «상위 우선 + 폴백 유지»

- 소프트 탐침은 실루엣이 만든(그러나 하드체크에서 거절된) hull 을 되살리는 **도달 복구**다
  — hull 자체가 0.5셀+ 어긋나면 원리적으로 못 잡는다 (직전 레인 규명).
- 블록 로케이터는 그 hull 을 아예 쓰지 않는 **기하 생성**이라 상위 호환이지만,
  블록 앵커 검출이 실패하는 프레임(모션 블러로 링 소실 등 실사 변수)이 남을 수 있어
  **폴백으로 유지**한다. 배선: 로케이터가 CS 수용 기하를 만들면 탐침 생략(발동 프레임
  +\~520 ms 절약), 못 만들면 종전 조건 그대로 발동 — 종전 대비 악화 경로 없음.
- 합성 98 매트릭스 기준 톤 커브 실패 프레임(종전 46)은 전부 로케이터가 수용 기하를

## 못 한 것 · 확신 없는 것

1. **실사 검증 미실시** — 합성 98+30+49 매트릭스가 전부지만, 실사 변수(모션 블러·초점·
   반사)에서의 블록 앵커 검출률은 재배포 후 실측이 필요하다. 특히 실사 120° 슬롯 회생
   여부는 여기서 «구조적 면역» 논증까지만 — 실측 확정은 범위 밖.
2. **120° 슬롯 사멸의 결정 지점은 추정 기록** (수정 안 함) — hull 꼭짓점 0 선정 규약 ×
   `cubeGeometrySeeds` 짝수 shift 커버리지의 교차점. 합성에서 죽음 자체가 재현되지 않아
   합성으로는 확정 불가.
3. **강한 원근(≥20°) + 강한 톤 커브 복합**은 미측정 — 이번 벤치는 톤×회전 축.
   기하왜곡 단독은 기존 스위트가 커버하고, 로케이터 정합(최소제곱 호모그래피)은 원근
   자유도를 갖지만 초기 포즈가 similarity 라 극단 원근에서는 실루엣 경로 의존이 남는다.
4. 일부 회전+강커브 조합(v2r2 105/240°)의 1.6\~3.0 s 는 기존 실루엣 flat-block recovery
   비용 — 로케이터 도입 전에도 같았고(기준 벤치 2.9 s), 이번 범위에서 손대지 않았다.
   실기기 1.5\~2 s 예산에 걸치는 프레임이 있다는 사실 자체는 기존 부채로 남는다.
5. 로케이터가 무왜곡 프레임에서도 가설을 추가하므로 top-1 가설의 «출처»가 표준 경로에서
   로케이터로 바뀌는 프레임이 있다 (복호 결과·수용은 전 케이스 불변 확인). 출처 통계를
   쓰는 텔레메트리가 있다면 분포 변화가 보일 수 있다 — 계측 의미는 불변.
