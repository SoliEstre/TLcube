## 4. 로케이터 판별 구조 (조기 분기 설계)

```
1-D 이진화 라인/레이 스캔 (기존 프리미티브 그대로)
  → K3 코어(공유 중앙: v0·v1r2·개정 v2r2) / K5 코어(원거리·legacy) 클러스터
  → 검증: 'v0-center'(공유 K3) · 'v2r2-corner'(열린 K5) · 'legacy-v2r2-center'(닫힌 K5 — 소각, 비소비)

앵커드 조립 (2차 앵커 존재 시):
  K3 중앙 × K5 코너 쌍 → estimatedRadius = 거리/u
    ├─ |r − 17.5| ≤ 3.2 → v2r2@21 similarity 시드 → refinePose(v2r2@21 패치)
    ├─ |r − 21.5| ≤ 3.2 → v2r2@25 similarity 시드 → refinePose(v2r2@25 패치)
    └─ |r − 18.0| ≤ 3.2 → v1r2 similarity 시드 → refinePose(v1r2 패치)   [겹치면 전부]
  → 성립한 중앙은 anchoredCentres 에 기록

폴백 (2차 앵커 부재/실패 중앙만):
  v0 360°×4스케일 템플릿 스윕 → refinePose(v0 패치)

수용: 전 포즈가 cellSurfaceOnly shape → CS 평가가 n 별 후보 레이아웃 전부 채점
  (n=21 은 v2r2·v1r2 병행) → 기존 게이트(agreement 0.78 · margin 0.035 ·
  tone span 0.012)가 판정. formatIndex 불변 (2톤=1 · 3톤=3).
```

## 5. 벤치 중 잡은 결함 2건 (둘 다 수정 완료)

### ① n 오스냅 — «가장 가까운 n 단독 스냅» 이 진짜 포즈를 굶긴다

1차 post 벤치(`_bench-post.txt`)에서 v2r2@21 이 **46/49** 로 3건 실패
(sCurve0.6 rot135 · gamma0.7 rot105 · gamma0.6 rot120). 원인 실측:

- 톤 커브가 중앙의 밝은 링을 침식해 u(셀 크기 추정)가 부풀면 estimatedRadius 가
  21↔25 겹침 구간(18.3\~20.7셀)으로 들어간다 (rot135 실측 19.7셀).
- 종전 «가장 가까운 n 단독 스냅» 규칙이 25 를 골라 **진짜 21 포즈가 아예 시드되지
  않았다** — n=25 오포즈는 CS 게이트가 걸러도 21 포즈가 없으니 프레임이 죽는다.
- 수정: **허용폭(±3.2셀) 안 후보 전부 시드** — v1r2 처리와 같은 원칙(후보를 다 세우고
  정합 점수·CS 게이트가 고른다). 게이트·formatIndex 불변, 결정성 유지.
- 수정 후 2차 post 벤치(`_bench-post2.txt`): **네 타깃 전부 49/49 (196/196)**.

### ② 중복 포즈 — shape 마다 도는 하류 CS 평가가 곱절 (시간 부채)

새 구조에서 n=21 프레임의 복호 중앙값이 723→1444\~1851 ms 로 튀었다. 원인 두 겹:

- **같은 자리 중복 히트**: k3·k5 클러스터가 같은 물리 앵커를 각각 검증해 같은 kind
  히트가 겹으로 남고(실측: 같은 좌표의 v0-center 2겹, v2r2-corner 2겹), 사실상 같은
  H 가 패밀리마다 2포즈로 조립된다.
- 하류(`cube-detect.hypothesesFromShapes`)는 **shape 마다** 3방향 × 시드 × CS 평가
  (n² 표본 · n=21 은 2레이아웃)를 돌므로 shape 수가 비용에 직결된다.

시도 1 — 조립 입구 **히트 위치 dedupe**: 클린 재벤치(`_bench-post3-part.txt`)에서 **기각**.
중복이 차지하던 상위 슬롯(중앙 3 · 코너 4)에 데이터 필드의 우연 K3 가 들어와, 실패
정합 + v0 스윕 비용이 중복 성공 정합보다 비쌌다 (v1r2 클린 724→1620 ms). revert —
상위 3/4 슬라이스가 사실상의 비용 캡임을 주석으로 기록.

시도 2 (채택) — **포즈 기하 dedupe** (`dedupePosesByGeometry`): 같은 패밀리·같은 n 에서
투영 원점·투영 대각점이 각각 2셀 이내로 겹치는 포즈를 중복으로 보고 최고점만 남긴다.
회전이 다른 포즈는 대각점이 갈라져 살아남고, 우연 K3 는 애초에 상위 슬롯을 못 뺏는다.
score 내림차순 고정 순회 — 결정성 유지. 로케이터 회귀 13/13. 최종 수치는 §6.
